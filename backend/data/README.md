# Country bounds

`country_bounds.json` contains English country labels and component bounding boxes
derived from Natural Earth 5.1.1 Admin 0 Countries at 1:110m scale. It supplies
compact component boxes for country results whose Photon extent wraps around the
full longitude range (notably the United States). Other place searches use Photon
extents directly.

Source: [Natural Earth Admin 0 Countries](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/),
[versioned GeoJSON](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.1/geojson/ne_110m_admin_0_countries.geojson).
Natural Earth data is public domain.
